Set up your free proxy

MangaDex blocks direct API calls from browsers. You need a tiny free proxy on Vercel. Takes about 2 minutes.

1
Go to github.com/new and create a new public repo called inkflow-proxy
2
Inside that repo, create a file at api/proxy.js — use the file I gave you in the download.
3
Go to vercel.com, sign up free, click Add New → Project, import your inkflow-proxy repo and deploy.
